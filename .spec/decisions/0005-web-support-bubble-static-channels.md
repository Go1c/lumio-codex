# 0005 · 官网客服气泡初版把社群入口写进前端配置，不接后台

- 日期：2026-08-17
- 状态：生效

## 背景

Workflow 的客服气泡由 `GET /support/config` 驱动，后台可改飞书群、邮箱与收件开关。
Lumio 官网三站是纯静态 SPA，没有对等的运营配置面，又要当天先把右下角入口上线。

## 决策

**初版只做 QQ 群 + 飞书群两条外链，URL 收敛在 `web/packages/ui/src/config.ts`，构建期可用环境变量覆盖。**

不移植 Workflow 的在线对话、Bug / 需求表单、健康探针，也不为这枚气泡新增 API。
某条 URL 为空就不渲染对应入口，避免空占位装成「已经配好了」。

## 后果

- 换群或关掉一条通道必须改配置并重新构建发布，不能在服务器上热改。
- 飞书默认值来自 Workflow 线上群；Lumio 若要独立群，覆盖 `VITE_SUPPORT_FEISHU_URL` 即可。
- 日后若要后台可配，应另开 ADR，把 `supportChannels()` 换成唯一读取点，而不是在页面里再写一份。
