# 0006 · 官方应用首次安装允许用户选择安装目录（Windows 便携路线升为一等选项）

- 日期：2026-08-16
- 状态：生效
- 关联：[0005 · 首次安装官方桌面应用](0005-lumio-first-official-app-install.md)、QA D-23

## 背景

用户反馈首次安装官方 Codex「不能在最一开始选择安装到哪个盘哪个目录」。平台约束：Windows 主路线是 MSIX 侧载（`Add-AppxPackage`），安装位置由 Windows 系统管理，客户端无法逐应用指定目录；macOS 的 .app 拷贝目标天然可控。

## 决策

1. 首次安装点主按钮先弹「选择安装位置」：Windows 摆两个并列选项——「标准安装（推荐）」走 MSIX（附「装后可在 系统设置 → 应用 中移动」提示）与「选择安装目录…」弹系统目录选择器走**便携解压**；macOS 为「默认位置（/Applications）」与「选择文件夹…」。
2. 默认选中标准安装：便携路线无包身份，「可能自退」尚未真机验证（D-18 记录），不做无数据支撑的默认切换；验证后再议。
3. 安全防线不降级：便携路线仍强制 Authenticode 钉选（D-21 三态规则的 `Mismatch` 拒 / `Unavailable` 拒保持不变，`Unavailable` 放行仅限侧载）。
4. 安装成功即删下载的安装包（失败保留供重试），避免 745MB 常驻缓存盘。
5. 仅当用户自选目录时，把**最终安装路径**落 `state_dir()/official-app-path.json`，启动检测优先读它、失效回落自动扫描；默认路线不写该文件。

## 弃选备选

- 默认弹目录选择器（便携为主路线）：赌未验证的自退风险，弃。
- 下载缓存迁移到目标盘：装后清包已把缓存盘峰值压到下载瞬时，不再叠加分支，弃。
- 仅 macOS 支持选目录：不解决用户报告的 Windows 场景，弃。

## 后果

- 自选目录装的官方应用卸载 = 删目录（无系统卸载项）；标准安装不受影响。
- 自定义安装路径失效（用户删/移目录）时回落自动扫描，可能重新触发「未安装」引导，属诚实降级。
- 剩余空间预检、设置页手动路径持久化（D-3）仍为已知缺口，另行任务。
