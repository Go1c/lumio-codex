# 0006 · 客服气泡的 QQ 入口是群号（可复制），不是加群 URL

- 日期：2026-08-17
- 状态：生效

## 背景

ADR-0005 把初版客服入口写成「QQ 群 + 飞书群两条外链」。实际运营给的是 QQ 群号
`1073671738`，没有加群 URL。

## 决策

**QQ 在气泡里展示群号，点击复制；飞书仍走加入链接。**

群号默认写在 `supportChannels()`，可用 `VITE_SUPPORT_QQ_NUMBER` 覆盖。

## 后果

- 用户要自己打开 QQ 搜索 / 加入该群，页面不承诺一键拉起 QQ 客户端。
- ADR-0005 里「两条外链」的表述被本条修正，其余（静态配置、不接后台）仍生效。
