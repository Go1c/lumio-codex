## Short description (≤ 300 chars)

Desktop launcher for official OpenAI Codex (zero-config sign-in) and official Claude Code on your own server. Does not modify the official apps. Independent project.

## Long description

BestCodex is one installer with two tabs.

Codex: sign in inside the app; it writes the local connection config and launches the official Codex application. No base URL or API key form. The official app is not bundled and not patched.

Claude: runs official Claude Code on a server you control — isolated environment, stable IP, persistent sessions, two-way file sync. This can lower environment-based account risk. It does not guarantee you will not be banned.

Pricing: Claude usage is drawn from a balance (¥19.9 is a reference top-up, not an auto-renewing subscription). Codex uses the same account balance.

Current releases are unsigned betas. macOS may report the app as damaged until the quarantine attribute is cleared (`xattr -cr` or the install script).

Not affiliated with OpenAI or Anthropic. Not related to third-party API relays that share a similar name. Only official site: bestcodex.app.
