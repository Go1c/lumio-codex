## 批 2：web 三站（W-1 / W-10 / W-17）

**W-1（P1）refresh 闭环**
- `web/packages/auth/src/session.ts`：
  - 新增 `readRefreshToken()` 与 `hasSession()`（access 或 refresh 任一存在即 true）。
  - 新增 `rotateSession(force)`：在 `navigator.locks.request`（特性检测，无则直接执行）锁内重读 cookie → 无 refresh 返回 false → 非 force 且 access 已在（他页刚轮换过）直接 true → 否则 `refreshTokens` + `writeSession`。锁内重读解决多标签页轮转互杀（旧 rt 失效 → REFRESH_TOKEN_REUSED 撤族）。
- `useSession.tsx`：初始 status 用 `hasSession()`（避免刷新期间闪「未登录」）；effect 分支：无 access 但有 refresh → `rotateSession(true)` → 成功后 `readSession()` 取新 access 拉 profile，失败 → `clearSession` + anonymous；既有 AUTH_SESSION_EXPIRED 刷新路径同样改走 `rotateSession(true)`。`accessToken` 消费方（Authorize 页）已有 `Boolean(accessToken)` 防护，兼容。
- 测试：`use-session.test.tsx` 补「仅 refresh cookie → 刷新成功 → authenticated」「刷新失败 → anonymous + 清 cookie」；`session.test.ts` 补新 helper。

**W-10（P2）复制 toast**
- `Authorize.tsx` `copyCode`：成功 toast 移入成功分支；失败/无 clipboard API 时提示「复制未成功，请手动选中复制」。补测试。

**W-17（P1）深链死链**

## 批 3：Go 控制面（S-1 / S-2 / S-5 / S-8 / S-9 / S-12）

**S-1（P1）TOTP 限频 + 失败锁定**
- `internal/service/service.go`：加 `RuleAdminTOTPByIP`（10/min）。
- `internal/api/middleware.go`：`rateLimitAdminTOTP`（键 `admin-totp:ip:`+ClientIP）；`api.go` 路由挂载。

- 测试：`test/admin_test.go` 集成用例 + 限频单测。

**S-2（P1）会话绝对寿命上限**
- `internal/config/config.go`：`SessionAbsoluteTTL`（默认 14 天，`CCHAVEN_SESSION_ABSOLUTE_TTL` 可配）。
- `internal/service/session.go` `RefreshSession`：`family.CreatedAt + TTL <= now` → `apperr.SessionExpired()`（`created_at` 列已存在，无需迁移）。到期后桌面端走既有浏览器重新授权流程，重新过 Sub2API 校验——把「停用永不生效」收敛为「≤14 天生效」。

- 测试：`test/oauth_test.go` 用注入时钟/直改 `created_at` 验证超期拒刷新。

**S-5（P2）支付金额校验**

**S-8（P2）邮件 worker 超时 + 事务外置 + 退避**
