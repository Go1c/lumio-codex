接入之后：右侧到底长什么样

真机上原来是「整页黑终端」：连上就丢进黑窗，Claude 甩出几十行登录地址， 顶上还写着「没能打开终端。」而下面 Claude 明明在跑。 已定案：方案 D。A / B / C 留在下面当决策留痕。

定案 · 方案 D：三栏 + 分阶段

期一

初始化

第一次接上这台服务器。终端里还没东西可看，中间那格是五步清单：连接 / 装同步组件 / 首次同步 / 装 Claude / 登录 Anthropic。登录就地给浏览器按钮和贴码框。

打开期一
首次同步 装 Claude 装失败 需登录 完成

期二

日常使用

左边按服务器分组列项目（一台服务器 N 个项目），中间顶部一条会话标签、下面整格终端，右边文件，底栏一行细状态。塞不进小字的表格与差异对比，点底栏从下面升起抽屉。

打开期二
已就绪 有冲突 有新版 终端真失败 抽屉 · 服务器 抽屉 · 对话 抽屉 · 冲突差异

期三

退出后重新进来

左栏列出所有项目（名称 / IP / 文件夹 / 上次状态），点一下就自动连接，不再问任何东西。登录过期用浮层，连不上则强调本机目录仍可用。

打开期三
刚进来 正在连接 登录过期 离线
方案 D 的四条硬规矩。 一，中间归终端，状态一律走底栏那行小字，且必须说清「你现在卡在哪」，不再只说「本机目录已就绪」。 二，「没能打开终端。」只允许在终端真的没打开时出现，且带重试；一旦有输出必须消失。 三，左栏只有项目和它的关键信息——名称、服务器 IP、文件夹、上次状态。没有订阅行，没有开通记录。 四，冲突不打断：底栏红角标加右栏文件角标，处理入口在抽屉里，`keepLocal` / `keepRemote` / `keepBoth` 与不静默覆盖照旧。

已定的另外四项。Claude 装在你自己的 Linux 服务器上，走官方签名安装包并校验，不用 sudo、不套安装脚本； 安装挂在工作台的初始化清单里，接入向导仍是四步，老项目也走得到； 登录是「在浏览器中登录 + 正规输入框贴授权码」，凭据仍由官方 Claude 自己保管； 默认不自动进 Claude，点「开始对话」才进。

落选留痕

下面三套都被否了，留着是为了别再兜回来。

方案 A · 落选

上状态卡 + 下终端

中间一张会变的状态卡，卡下面才是终端。

为什么落选
状态卡常驻，永久吃掉终端的高度。日常使用时那张卡九成时间只是在说「已就绪」，却一直占着最贵的纵向空间。
打开方案 A

方案 B · 落选

三栏，文件冲突常驻右栏

左轨 + 中间状态卡与终端 + 右边常驻文件与冲突栏。

为什么落选
方向对了，但中间同时塞状态卡和终端，1080 宽的窗口里终端只剩 500 出头。D 保留了右栏文件，把状态挪去底栏，中间整格让给终端。
打开方案 B

方案 C · 落选

保留 Tab，加「概览」当默认

四个 Tab，默认落在概览。

为什么落选
状态和终端被 Tab 切开：安装时看不到日志滚，对话时看不到状态。每次确认「Claude 好了没」都要切页，跟「终端只是工具」反着走。
打开方案 C
还没画的（known gaps）： 文件面板的完整层级与预览（现在只画了树和角标）；抽屉里超过两个冲突时的列表分页； 底栏 CPU 与内存的刷新节奏按 30 秒一次画的，真机上要不要这么勤还得看开销。
