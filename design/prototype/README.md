# CC避风港 CCHaven 交互原型

> 产品名：**CC避风港（CCHaven）**——圈内「CC」即 Claude Code 简称，「避风港」直指「防封号的安全港」定位；刻意不用「Claude」全称以规避商标风险。演示域名 cchaven.cn。

可点击高保真原型，配合 [../../docs/design/interaction-design.md](../../docs/design/interaction-design.md) 评审使用。独立于主代码库，不影响 `apps/desktop`。

## 运行

```bash
npm install
npm run dev
```

## 演示说明

- 界面语言：简体中文（默认 zh-CN）。
- 右下角悬浮条可随时切换「官网 / APP」，点「载入演示数据」可直接进入已登录且带示例项目的 APP；勾选**显示错误状态**查看各页面的失败分支（登录失败、验证码错误、SSH 连接失败、部署失败、断线重连、加载失败、邀请列表为空等）。
- 主链路：官网首页／邀请落地页（`/#/i/demo`）→ 注册（含邀请横幅）→ 邮箱验证码（演示码 `123456`）→ 下载页 → 打开 CC避风港 APP → 「通过浏览器登录」授权（APP 内无密码输入；经邀请进入时授权后弹出试用开通提示）→ 空状态 → 新建项目三步向导（小白友好：填 IP+root 密码即可，支持粘贴 ssh 命令自动识别，远端/本地目录自动预设，连接失败给排查清单）→ 工作区（顶部信息栏 + 终端 / 文件[VS Code 式资源管理器：新建/重命名/删除/右键菜单/标签页] / 冲突）。
- 管理员运营后台：悬浮条点「后台」或访问 `/#/admin`——仪表盘（日活/注册/收入/转化/留存 + 平台/版本/来源分布）、用户（搜索/筛选/禁用）、订单与付款（筛选/退款/导出）、运营配置（邀请奖励天数/试用时长/包月价格，对应「后台可配置」）。
- APP 内账户只有侧栏底部的弹出菜单（订阅剩余天数 + 官网链接 + 退出登录）；订阅充值、个人资料、邀请好友、安全、登录设备统一在官网 `/#/account` 账户中心管理，APP 不处理付款。
- 邀请机制双向奖励：被邀请者获首月免费试用（每账号一次）；邀请者每成功邀请 1 人订阅延长 X 天（演示中 X=7，实际由后台配置，可配 0 关闭）。
- 演示中的时间参数已压缩（验证码重发冷却 10 秒，规格为 60 秒）。
